# SecureTrace

SecureTrace is a full-stack cybersecurity application.

## Project Structure

- `backend/` - Spring Boot REST API
- `frontend/` - React/Vite frontend

## Technologies

### Backend
- Java
- Spring Boot
- Spring Security
- JPA/Hibernate
- MySQL

### Frontend
- React
- Vite
- JavaScript

## Running Locally

### Backend

```bash
cd backend
mvnw.cmd spring-boot:run
